# LoginButton.tsx

## Purpose

Authentication button component that handles Privy login/logout flow. Displays loading spinner during initialization, shows truncated Solana wallet address when authenticated with logout button, and shows Google sign-in button for unauthenticated users.

## Exports

- `LoginButton` - Authentication state display and action button

## Dependencies

- [[pwa-app-hooks-usePrivyAuth]] - Privy authentication state and methods
- [[pwa-app-utils-logout]] - Logout utility with user type routing
