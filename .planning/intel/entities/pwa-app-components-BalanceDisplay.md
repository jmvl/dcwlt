# BalanceDisplay.tsx

## Purpose

Wallet balance display component showing Event Token balance from Solana Devnet. Features balance masking toggle, refresh button, loading states, error handling, and fiat conversion display (mock $0.10/EVT rate).

## Exports

- `BalanceDisplay` - Token balance display component with mask/refresh controls
