# QRScanner.tsx

## Purpose

Camera-based QR code scanner component using qr-scanner library. Handles camera permissions, uses back camera on mobile, provides error handling for permission denied/camera not found scenarios, and gracefully cleans up scanner on unmount.

## Exports

- `QRScanner` - Camera QR scanner with success/error callbacks

## Dependencies

- qr-scanner - QR code scanning library with camera integration
