# PrivyProvider.tsx

## Purpose

Privy authentication provider wrapper component. Configures Privy for embedded Solana wallet creation, Solana Devnet RPC connections, and dark theme styling. Prevents SSR hydration issues with client-side rendering check.

## Exports

- `PrivyAuthProvider` - Privy authentication provider component

## Dependencies

- @privy-io/react-auth - Privy authentication SDK
- @solana/kit - Solana RPC and subscription utilities
- NEXT_PUBLIC_PRIVY_APP_ID - Privy application identifier
