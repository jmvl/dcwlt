# admin/inventory/page.tsx

## Purpose

Inventory configuration page for managing event-level item groups and merchant assignments. Two-tab interface for item group management (groups/items) and merchant group assignments (which merchants sell which items at which events).

## Exports

- `InventoryManagementPage` - Comprehensive inventory and assignment management interface

## Dependencies

- api.events - Event data for inventory assignment
- api.itemGroups - Item group CRUD operations
- api.merchantEvents - Merchant-event assignment queries
- [[pwa-app-admin-inventory-components-TabNavigation]] - Tab switcher component
- [[pwa-app-admin-inventory-components-GroupCard]] - Item group display card
- [[pwa-app-admin-inventory-components-ItemCard]] - Item display card
