# formatTime.ts

## Purpose

Transaction timestamp formatting utility for human-readable relative time display. Formats timestamps as "Just now", "Xm ago", "Today, H:MM PM", "Yesterday", or abbreviated date for older transactions.

## Exports

- `formatTransactionTime(timestamp)` - Formats Unix timestamp to relative time string

## Dependencies

- None (standard Date APIs)
