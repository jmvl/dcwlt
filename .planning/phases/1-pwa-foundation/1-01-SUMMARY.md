## Decisions Made

1. **PWA plugin choice:** Used `@ducanh2912/next-pwa` instead of `next-pwa` - the former is actively maintained for Next.js 16 with Turbopack support
2. **Turbopack compatibility:** Added `turbopack: {}` to Next.js config to resolve webpack/turbopack conflict caused by PWA plugin's internal webpack config
3. **Viewport export separation:** Moved viewport and themeColor to separate `viewport` export per Next.js 16 requirements (warnings without this)
4. **Icon generation approach:** Created Python PIL script instead of using ImageMagick - more portable, no external system dependency, works on macOS without brew install
5. **Purpose field value:** Used `"purpose": "any"` instead of `"any maskable"` - TypeScript type error with space-separated value (Next.js manifest types expect single value)
