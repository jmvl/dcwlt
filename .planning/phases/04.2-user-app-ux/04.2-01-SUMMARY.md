## Privy Integration Constraints

The Privy action sheet that appears during `signTransaction()` call (line 106 in `usePayment.ts`) is a **security feature** that cannot be disabled:

- User must explicitly authorize the transaction in Privy's UI
- This is part of Privy's embedded wallet security model
- The "Transaction Signed" close button is part of Privy's modal and cannot be customized
- The `appearance` config in PrivyProvider only controls theming (colors, dark mode), not modal behavior

This is expected behavior for non-custodial wallet security.
