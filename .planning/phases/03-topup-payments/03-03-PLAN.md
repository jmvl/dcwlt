    Create pwa/src/utils/transactions.ts with buildSPLTokenTransfer function:

    Function signature:
    ```typescript
    export async function buildSPLTokenTransfer(params: {
      recipient: string;
      amount: string;
      splToken: string;
      sender: string; // wallet address
    }): Promise<Transaction>
    ```

    Implementation:
    1. Import from @solana/kit:
       - createTransactionMessage, setTransactionMessageFeePayerSigner
       - setTransactionMessageLifetimeUsingBlockhash, appendTransactionMessageInstructions
       - createSolanaRpc, getLatestBlockhash
       - getTransferInstruction from @solana/program/token
    
    2. Convert amount from string to bigint:
       - Event Token has 9 decimals
       - Amount in smallest unit = amount * 10^9
       - Use BigInt(amount) * BigInt(100000000)
    
    3. Fetch latest blockhash from Devnet RPC:
       - RPC URL: https://api.devnet.solana.com
       - Use createSolanaRpc().getLatestBlockhash().send()
    
    4. Build transaction using pipe pattern:
       - createTransactionMessage({ version: 0 })
       - setTransactionMessageFeePayerSigner(sender address)
       - setTransactionMessageLifetimeUsingBlockhash(blockhash)
       - appendTransactionMessageInstructions with getTransferInstruction()
    
    5. Return transaction object for signing

    Include TypeScript types and error handling.
  </action>
  <verify>TypeScript compiles, function exports correctly</verify>
  <done>Transaction builder utility for SPL token transfers</done>

<task type="auto">
  <name>Task 3: Create usePayment hook</name>
  <files>pwa/app/hooks/usePayment.ts</files>
  <action>
    Create pwa/app/hooks/usePayment.ts with payment signing and submission logic:

    Hook signature:
    ```typescript
    export function usePayment() {
      return {
        executePayment: (params: PaymentParams) => Promise<PaymentResult>
      }
    }
    ```

    Implementation:
    1. Import { usePrivy } from '@privy-io/react-auth'
    2. Import buildSPLTokenTransfer from '@/utils/transactions'
    3. Import createSolanaRpc from '@solana/kit'
    
    executePayment function:
    1. Get signTransaction from usePrivy()
    2. Build transaction with buildSPLTokenTransfer()
    3. Sign transaction: const signature = await signTransaction(transaction)
    4. Create RPC client: const rpc = createSolanaRpc('https://api.devnet.solana.com')
    5. Submit transaction: await rpc.sendTransaction(transaction, { encoding: 'base64' }).send()
    6. Return { success, signature, error }
    
    Error handling:
    - Insufficient balance: "Insufficient funds for this payment"
    - Invalid transaction: "Invalid transaction details"
    - Network error: "Network error, please try again"
    - Signing failed: "Failed to sign transaction"
    
    Use React hooks pattern with useState for loading state.
  </action>
  <verify>Hook compiles, Privy integration correct</verify>
  <done>Payment hook with signing and submission</done>
</task>
