<task type="auto">
  <name>Task 2: Create Solana Pay URL parser utility</name>
  <files>pwa/src/utils/solanaPay.ts</files>
  <action>
    Create pwa/src/utils/solanaPay.ts with:

    1. parseSolanaPayURL(url: string) function:
       - Removes "solana:" scheme prefix
       - Splits on '?' to separate address from query params
       - Parses query parameters using URLSearchParams
       - Returns object: { recipient, amount, splToken, reference, label, message }
       - All values are strings or null
       - Throws error if URL format is invalid

    2. isValidSolanaPayURL(url: string) function:
       - Checks if URL starts with "solana:"
       - Validates recipient is present (after scheme)
       - Returns boolean
       - Does NOT throw, returns false for invalid URLs

    3. SOLANA_PAY_URL_PATTERN constant:
       - Regex pattern: /^solana:[1-9A-HJ-NP-Za-km-z]{32,44}(\?.*)?$/
       - Matches Solana Pay URL format with Base58 address
       
    Include TypeScript types for return values and parameters.
  </action>
  <verify>TypeScript compiles, functions export correctly, regex pattern valid</verify>
  <done>URL parser utility with validation</done>
</task>
