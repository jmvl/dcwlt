## Security Considerations

- Uses Web Crypto API (`crypto.subtle`) - browser native, no external dependencies
- Server secret is passed as parameter, never stored in client
- No `NEXT_PUBLIC_` env vars exposing secrets
- HMAC-SHA256 provides cryptographically secure signatures
