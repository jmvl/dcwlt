# Phase 5.5: Cryptographic QR Payment - Research

**Researched:** 2026-03-06
**Domain:** Reverse payment flow with cryptographic QR codes (TOTP-like, HMAC signatures, Convex atomic transactions)
**Confidence:** HIGH

## Summary

Phase 5.5 implements a **reverse payment flow** where the customer generates a dynamic cryptographic QR code that the merchant scans to receive payment. This inverts the traditional "merchant displays QR, customer scans" model to mirror real-world card payments where customers present payment credentials.

The implementation combines three key technologies:
1. **TOTP-like time-based key derivation** - Uses `otplib` for generating time-based keys that change every minute
2. **HMAC signatures** - Uses Web Crypto API (or `jose` library fallback) for cryptographic signing
3. **Convex atomic mutations** - Leverages existing `transferBalance` mutation for instant, atomic payment processing

**Primary recommendation:** Use the existing `transferBalance` mutation as the payment execution mechanism. Extend it to support QR-based payment verification with a new internal mutation that validates the QR signature, timestamp, and executes the transfer atomically.

### Pattern 1: TOTP-Based Key Derivation

**What:** Generate time-based keys using otplib with custom secret derivation
**When to use:** QR generation on client and verification on server

**Example:**
```typescript
// Source: https://github.com/yeojz/otplib
import { totp } from 'otplib';

// Client-side: Generate time key
const generateTimeKey = (derivedSecret: string): string => {
  return totp.generate(derivedSecret);
};

// Server-side: Verify time key (with clock skew tolerance)
const verifyTimeKey = (token: string, derivedSecret: string): boolean => {
  // otplib allows +/-1 window by default for clock skew
  return totp.check(token, derivedSecret);
};

// Configure for 60-second window (changes every minute)
totp.options = {
  step: 60,           // 60 second window
  window: 2,          // Allow 2 windows back/forward for clock skew
};
```

### Pattern 2: HMAC Signature for QR Payload

**What:** Sign the QR payload (userId + timeKey) with HMAC-SHA256
**When to use:** QR generation and verification

**Example (using Web Crypto API directly):**
```typescript
// Source: MDN Web Crypto API
const signPayload = async (userId: string, timeKey: string, secret: string): Promise<string> => {
  const encoder = new TextEncoder();
  const keyData = encoder.encode(secret);
  const message = `${userId}:${timeKey}`;

  const cryptoKey = await crypto.subtle.importKey(
    'raw',
    keyData,
    { name: 'HMAC', hash: 'SHA-256' },
    false,
    ['sign']
  );

  const signature = await crypto.subtle.sign(
    'HMAC',
    cryptoKey,
    encoder.encode(message)
  );

  // Return as hex string
  return Array.from(new Uint8Array(signature))
    .map(b => b.toString(16).padStart(2, '0'))
    .join('');
};

const verifySignature = async (
  userId: string,
  timeKey: string,
  signature: string,
  secret: string
): Promise<boolean> => {
  const expectedSignature = await signPayload(userId, timeKey, secret);
  return expectedSignature === signature;
};
```

### Pattern 3: Convex Atomic Payment Mutation

**What:** Single mutation that validates QR and transfers balance atomically
**When to use:** Payment processing when merchant scans customer QR

**Example:**
```typescript
// Source: Convex docs - GenericMutationCtx
// All operations within a mutation are atomic and isolated
export const processQRPayment = internalMutation({
  args: {
    customerPrivyId: v.string(),
    timeKey: v.string(),
    signature: v.string(),
    merchantId: v.id("merchants"),
    amount: v.number(),
    itemId: v.optional(v.id("groupItems")),
  },
  handler: async (ctx, args) => {
    // 1. Get server secret from environment
    const serverSecret = process.env.QR_SIGNING_SECRET;
    if (!serverSecret) throw new Error("Server configuration error");

    // 2. Derive customer's secret (same way client does)
    const derivedSecret = deriveSecret(args.customerPrivyId, serverSecret);

    // 3. Verify time key (with clock skew tolerance)
    if (!totp.check(args.timeKey, derivedSecret)) {
      throw new Error("Invalid or expired QR code");
    }

    // 4. Verify HMAC signature
    const isValid = await verifyHMAC(
      args.customerPrivyId,
      args.timeKey,
      args.signature,
      serverSecret
    );
    if (!isValid) {
      throw new Error("Invalid QR signature");
    }

    // 5. Execute atomic transfer (reuses existing logic)
    // This is atomic - if any step fails, everything rolls back
    return await ctx.runMutation(internal.wallets.transferBalance, {
      senderPrivyId: args.customerPrivyId,
      recipientWalletAddress: await getMerchantWallet(ctx, args.merchantId),
      amount: args.amount,
      merchantId: args.merchantId,
      itemId: args.itemId,
    });
  },
});
```

### Anti-Patterns to Avoid

- **Don't use wallet private key for signing**: The PWA doesn't have access to wallet private keys. Use server-side secret + user ID for derived secrets.
- **Don't create separate validate + transfer mutations**: This breaks atomicity. Use a single internal mutation.
- **Don't use Date.now() for time windows**: Use `totp` library which handles Unix epoch properly.
- **Don't forget rate limiting**: Without it, users could generate thousands of QR codes.

## Don't Hand-Roll

| Problem | Don't Build | Use Instead | Why |
|---------|-------------|-------------|-----|
| Time-based key generation | Custom counter + hash | otplib TOTP | Handles clock skew, counter rollover, standard algorithm |
| HMAC signing | Custom crypto implementation | Web Crypto API or jose | Browser-native, hardware-accelerated, well-tested |
| QR code generation | Custom matrix library | qrcode.react | Handles error correction, encoding, canvas rendering |
| Rate limiting | Custom counter table | @convex-dev/ratelimiter | Atomic, distributed-safe, integrates with Convex |

**Key insight:** The cryptographic operations in this phase are security-critical. Using battle-tested libraries prevents subtle bugs that could lead to payment fraud.

## Common Pitfalls

### Pitfall 1: Clock Skew Between Client and Server
**What goes wrong:** Client generates valid QR, but server rejects it due to time difference
**Why it happens:** Client and server clocks may differ by several seconds
**How to avoid:** Use `totp.options.window = 2` to allow +/-2 time windows (120 seconds tolerance)
**Warning signs:** Users report "invalid QR" immediately after generation

### Pitfall 2: Secret Derivation Inconsistency
**What goes wrong:** Client and server derive different secrets from same inputs
**Why it happens:** Different encoding (UTF-8 vs ASCII), different concatenation order
**How to avoid:** Use exact same derivation function on both sides:
```typescript
const deriveSecret = (userId: string, serverSecret: string): string => {
  // Use base32 encoding (required by otplib)
  return Buffer.from(`${userId}:${serverSecret}`).toString('base64');
};
```

### Pitfall 3: Race Condition in Multi-Scan
**What goes wrong:** Same QR scanned twice rapidly, both succeed, balance goes negative
**Why it happens:** Convex mutations are atomic, but two separate mutations don't see each other
**How to avoid:** The existing `transferBalance` mutation already handles this - it's atomic within single mutation. Multiple rapid scans of same QR each create their own atomic transaction.

### Pitfall 4: Screen Brightness on iOS
**What goes wrong:** Screen brightness doesn't change on iOS when displaying QR
**Why it happens:** iOS has strict permissions for system brightness
**How to avoid:** Use app-level brightness (`BrightnessMode.SYSTEM` vs `BrightnessMode.APP`) which doesn't require permissions:
```typescript
import * as Brightness from 'expo-brightness';

// In QR modal component
useEffect(() => {
  if (isOpen) {
    Brightness.setBrightnessAsync(1.0); // Max brightness
  }
  return () => {
    Brightness.setBrightnessAsync(Brightness.getBrightnessAsync()); // Restore
  };
}, [isOpen]);
```

### Pitfall 5: QR URL Scheme Not Registered
**What goes wrong:** Merchant scanner reads QR but phone doesn't know how to handle `dcwlt://` URL
**Why it happens:** Custom URL schemes need no registration - the QR is just data, not a deep link
**How to avoid:** This is actually fine - the merchant scanner parses the QR as text data, not as a URL to open. The URL scheme is just a format convention.

### Complete QR Generation Hook

Verified pattern combining otplib and Web Crypto API:

```typescript
// pwa/app/hooks/useCryptographicQR.ts
import { totp } from 'otplib';
import { useQuery } from 'convex/react';
import { api } from '@/convex/_generated/api';
import { usePrivy } from '@privy-io/react-auth';
import { useState, useCallback, useEffect } from 'react';

// Configure TOTP for 60-second windows with clock skew tolerance
totp.options = { step: 60, window: 2 };

interface QRData {
  url: string;          // dcwlt://pay?u=USER_ID&k=TIME_KEY&s=SIGNATURE
  timeKey: string;      // Current TOTP value
  expiresAt: number;    // Unix timestamp when QR expires
  secondsRemaining: number;
}

export function useCryptographicQR() {
  const { user } = usePrivy();
  const privyId = user?.id;

  // Get the server-derived secret (computed server-side, returned to client)
  const secretData = useQuery(
    api.cryptographicQr.getQRSecret,
    privyId ? { privyId } : 'skip'
  );

  const [qrData, setQRData] = useState<QRData | null>(null);

  const generateQR = useCallback(async () => {
    if (!privyId || !secretData?.derivedSecret) return null;

    // 1. Generate time-based key
    const timeKey = totp.generate(secretData.derivedSecret);

    // 2. Create HMAC signature
    const message = `${privyId}:${timeKey}`;
    const signature = await signHMAC(message, secretData.signingKey);

    // 3. Build URL
    const url = `dcwlt://pay?u=${encodeURIComponent(privyId)}&k=${timeKey}&s=${signature}`;

    // 4. Calculate expiry (next TOTP window)
    const now = Date.now();
    const windowStart = Math.floor(now / 60000) * 60000;
    const expiresAt = windowStart + 300000; // 5 minutes from window start

    const qrData: QRData = {
      url,
      timeKey,
      expiresAt,
      secondsRemaining: Math.floor((expiresAt - now) / 1000),
    };

    setQRData(qrData);
    return qrData;
  }, [privyId, secretData]);

  // Auto-regenerate when approaching expiry
  useEffect(() => {
    if (!qrData) return;

    const timeUntilExpiry = qrData.expiresAt - Date.now();
    const refreshTime = Math.max(timeUntilExpiry - 10000, 0); // Refresh 10s before

    const timer = setTimeout(() => {
      generateQR();
    }, refreshTime);

    return () => clearTimeout(timer);
  }, [qrData, generateQR]);

  return { qrData, generateQR, isLoading: !secretData };
}

// Helper: HMAC signing using Web Crypto API
async function signHMAC(message: string, key: string): Promise<string> {
  const encoder = new TextEncoder();
  const keyData = encoder.encode(key);

  const cryptoKey = await crypto.subtle.importKey(
    'raw',
    keyData,
    { name: 'HMAC', hash: 'SHA-256' },
    false,
    ['sign']
  );

  const signature = await crypto.subtle.sign(
    'HMAC',
    cryptoKey,
    encoder.encode(message)
  );

  return Array.from(new Uint8Array(signature))
    .map(b => b.toString(16).padStart(2, '0'))
    .join('');
}
```

### QR Display Component

```typescript
// pwa/app/components/CustomerQRCode.tsx
'use client';

import { useEffect, useState } from 'react';
import { QRCodeSVG } from 'qrcode.react';
import * as Brightness from 'expo-brightness';
import { useCryptographicQR } from '@/app/hooks/useCryptographicQR';

interface CustomerQRCodeProps {
  isOpen: boolean;
  onClose: () => void;
}

export function CustomerQRCode({ isOpen, onClose }: CustomerQRCodeProps) {
  const { qrData, isLoading } = useCryptographicQR();
  const [brightnessRestored, setBrightnessRestored] = useState(false);

  // Auto-max brightness when QR displayed
  useEffect(() => {
    if (isOpen) {
      Brightness.setBrightnessAsync(1.0);
      setBrightnessRestored(false);
    } else if (!brightnessRestored) {
      // Restore brightness on close
      Brightness.restoreBrightnessAsync();
      setBrightnessRestored(true);
    }
  }, [isOpen, brightnessRestored]);

  if (!isOpen) return null;

  return (
    <div className="fixed inset-0 bg-black flex flex-col items-center justify-center z-50">
      {/* Countdown Timer */}
      <div className="text-white text-2xl font-bold mb-4">
        {qrData ? formatCountdown(qrData.secondsRemaining) : 'Loading...'}
      </div>

      {/* QR Code */}
      <div className="bg-white rounded-lg p-8">
        {isLoading ? (
          <div className="w-64 h-64 flex items-center justify-center">
            <div className="animate-spin rounded-full h-12 w-12 border-b-2 border-blue-500" />
          </div>
        ) : qrData ? (
          <QRCodeSVG
            value={qrData.url}
            size={256}
            level="M"
            bgColor="#FFFFFF"
            fgColor="#000000"
          />
        ) : (
          <div className="text-red-500">Failed to generate QR</div>
        )}
      </div>

      {/* Close Button */}
      <button
        onClick={onClose}
        className="mt-8 text-white underline"
      >
        Close
      </button>
    </div>
  );
}

function formatCountdown(seconds: number): string {
  const mins = Math.floor(seconds / 60);
  const secs = seconds % 60;
  return `${mins}:${secs.toString().padStart(2, '0')} remaining`;
}
```

### Merchant Scanner Component

```typescript
// pwa/app/merchant/scan-customer/page.tsx
'use client';

import { useEffect, useRef, useState } from 'react';
import { Html5Qrcode } from 'html5-qrcode';
import { useMutation } from 'convex/react';
import { api } from '@/convex/_generated/api';
import { useRouter } from 'next/navigation';

export default function ScanCustomerPage() {
  const scannerRef = useRef<Html5Qrcode | null>(null);
  const [scanning, setScanning] = useState(true);
  const [result, setResult] = useState<'success' | 'error' | null>(null);
  const [errorMessage, setErrorMessage] = useState<string | null>(null);

  const processPayment = useMutation(api.cryptographicQr.processQRPayment);

  useEffect(() => {
    if (!scanning) return;

    const html5QrCode = new Html5Qrcode('qr-reader');
    scannerRef.current = html5QrCode;

    html5QrCode.start(
      { facingMode: 'environment' },
      { fps: 10, qrbox: { width: 250, height: 250 } },
      async (decodedText) => {
        // Parse QR URL
        const parsed = parseCustomerQR(decodedText);
        if (!parsed) {
          setErrorMessage('Invalid QR code format');
          setResult('error');
          return;
        }

        try {
          // Get cart amount from context/state
          const cartAmount = getCartTotal(); // From cart context

          await processPayment({
            customerPrivyId: parsed.userId,
            timeKey: parsed.timeKey,
            signature: parsed.signature,
            merchantId: getCurrentMerchantId(),
            amount: cartAmount,
          });

          setResult('success');
          // Vibrate on success
          navigator.vibrate?.([100, 50, 100]);

          // Auto-dismiss after 3 seconds
          setTimeout(() => router.push('/merchant'), 3000);
        } catch (err: any) {
          setErrorMessage(err.message || 'Payment failed');
          setResult('error');
        }

        html5QrCode.stop();
        setScanning(false);
      },
      () => {} // Ignore scan errors
    );

    return () => {
      html5QrCode.stop().catch(() => {});
    };
  }, [scanning]);

  // ... render UI
}

function parseCustomerQR(url: string): { userId: string; timeKey: string; signature: string } | null {
  try {
    const parsed = new URL(url);
    if (parsed.protocol !== 'dcwlt:') return null;
    if (parsed.pathname !== '/pay') return null;

    return {
      userId: parsed.searchParams.get('u') || '',
      timeKey: parsed.searchParams.get('k') || '',
      signature: parsed.searchParams.get('s') || '',
    };
  } catch {
    return null;
  }
}
```
