## Architecture Notes

**NEW MODEL IMPLEMENTED**: Phase 3.5 now uses event-level item groups instead of per-merchant items.

**Benefits:**
- 90%+ reduction in duplicate data
- Shared item catalog across all merchants at an event
- Per-merchant pricing/stock overrides when needed
- Scalable for events with many merchants

**Backend: COMPLETE**
- Tables: `itemGroups`, `groupItems`, `merchantGroupAssignments`, `merchantItemOverrides`
- 16 mutations/queries in `itemGroups.ts`
- Legacy `inventory.ts` marked as deprecated

**Frontend: COMPLETE**
- Two-tab UI: "Item Groups" + "Merchant Assignments"
- Event-level catalog creation
- Per-merchant customization
