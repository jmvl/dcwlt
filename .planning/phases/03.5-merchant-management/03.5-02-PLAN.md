<task type="auto">
  <name>Task 1: Create approval and rejection mutations</name>
  <files>pwa/convex/merchants.ts</files>
  <action>
    Add to pwa/convex/merchants.ts:

    1. approveMerchant mutation:
       - Args: merchantId, adminNotes (optional)
       - Validates merchant exists and status="pending"
       - Updates merchant:
         * status: "approved"
         * reviewedAt: Date.now()
         * reviewedBy: current user ID (from ctx.auth)
         * notes: adminNotes
       - Returns updated merchant record
       - Error if merchant not found or not pending

    2. rejectMerchant mutation:
       - Args: merchantId, rejectionReason (optional)
       - Validates merchant exists and status="pending"
       - Updates merchant:
         * status: "rejected"
         * reviewedAt: Date.now()
         * reviewedBy: current user ID
         * notes: rejectionReason
       - Returns updated merchant record
       - Error if merchant not found or not pending

    Use ctx.auth.getUserIdentity() for admin user tracking (requires auth to be set up).
  </action>
  <verify>TypeScript compiles, mutations have proper type signatures</verify>
  <done>approveMerchant and rejectMerchant mutations implemented</done>
</task>
