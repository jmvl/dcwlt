<task type="auto">
  <name>Task 2: Create event CRUD operations</name>
  <files>pwa/convex/events.ts</files>
  <action>
    Create pwa/convex/events.ts with:

    1. createEvent mutation:
       - Args: name, type, customType (optional), date, venue, capacity
       - Validates required fields
       - Validates date is in future (optional, can skip for flexibility)
       - Validates capacity > 0
       - If type is "Custom", requires customType
       - Creates event with createdAt and updatedAt timestamps
       - Returns created event

    2. updateEvent mutation:
       - Args: eventId, updates (name, type, customType, date, venue, capacity)
       - Validates event exists
       - Updates provided fields
       - Updates updatedAt timestamp
       - Returns updated event

    3. getEvents query:
       - Returns all events ordered by date (upcoming first)
       - Optional: filter by type

    4. getEvent query:
       - Args: eventId
       - Returns event or null

    Use v.id("events") for eventId type.
  </action>
  <verify>TypeScript compiles, Convex functions have proper types</verify>
  <done>Event mutations and queries implemented</done>
</task>
