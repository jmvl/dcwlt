       - Subtext: "X approved, Y pending, Z rejected"
    2. Active Events: count of upcoming events
       - Subtext: "Next event: [Event Name] on [Date]"
    3. Total Assignments: count of merchant-event assignments
       - Subtext: "Across X events"
    4. Total Inventory Items: count of all inventory items
       - Subtext: "Across X merchants at Y events"

    Recent activity (left column):
    - List of recent merchant registrations (last 5)
    - Show: business name, status, applied at
    - Color-coded status badges
    - "View All" link to /admin/merchants

    Upcoming events (right column):
    - List of upcoming events (last 5, sorted by date)
    - Show: name, date, merchant count
    - "View All" link to /admin/events

    Quick actions section:
    - "Create New Event" button → navigates to /admin/events
    - "Review Pending Merchants" button → navigates to /admin/merchants with pending tab
    - "Configure Inventory" button → navigates to /admin/inventory

    Data fetching:
    - Use Convex queries for real-time data:
      * getAllMerchants (count by status)
      * getEvents (filter by date, count)
      * getEventAssignments (count total)
      * getEventInventory (count total items)
    - Real-time updates via subscriptions

    UI requirements:
    - Use Shadcn components (Card, Button, Badge)
    - Responsive grid layout
    - Loading states during data fetch
    - Empty states for no data
    - Color-coded status badges (approved=green, pending=yellow, rejected=red)
