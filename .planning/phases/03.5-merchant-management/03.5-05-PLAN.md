<task type="auto">
  <name>Task 2: Create inventory mutations and queries</name>
  <files>pwa/convex/inventory.ts</files>
  <action>
    Create pwa/convex/inventory.ts with:

    1. addItem mutation:
       - Args: merchantEventId, itemName, price, stock (optional), description (optional)
       - Validates merchantEvent exists
       - Validates price > 0
       - Creates inventory record
       - Returns created item

    2. updateItem mutation:
       - Args: itemId, updates (itemName, price, stock, description)
       - Validates item exists
       - Updates provided fields
       - Updates updatedAt timestamp
       - Returns updated item

    3. removeItem mutation:
       - Args: itemId
       - Validates item exists
       - Deletes item
       - Returns success

    4. getEventInventory query:
       - Args: eventId
       - Returns all items for this event with merchant details
       - Join inventory → merchantEvents → merchants
       - Includes: merchant name, booth number, item name, price, stock
       - Grouped by merchant (show which items belong to which merchant)

    5. getMerchantEventItems query:
       - Args: merchantEventId
       - Returns all items for this merchant-event assignment
       - Ordered by item name

    Use v.id("inventory") for item IDs.
  </action>
  <verify>TypeScript compiles, Convex functions have proper types</verify>
  <done>Inventory mutations and queries implemented</done>
</task>
