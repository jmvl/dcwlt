<task type="auto">
  <name>Task 2: Create assignment mutations and queries</name>
  <files>pwa/convex/merchantEvents.ts</files>
  <action>
    Create pwa/convex/merchantEvents.ts with:

    1. assignMerchantToEvent mutation:
       - Args: merchantId, eventId, boothNumber
       - Validates merchant exists and status="approved" (only approved merchants)
       - Validates event exists
       - Validates merchant not already assigned to this event
       - Creates merchantEvents record
       - Returns created record
       - Errors: "Merchant not found", "Merchant not approved", "Event not found", "Merchant already assigned to this event"

    2. removeMerchantFromEvent mutation:
       - Args: merchantEventId (or merchantId + eventId)
       - Validates assignment exists
       - Deletes merchantEvents record
       - Returns success

    3. getEventAssignments query:
       - Args: eventId
       - Returns all merchantEvents for this event with merchant details (join)
       - Includes: merchant business name, wallet address, booth number
       - Ordered by booth number

    4. getMerchantAssignments query:
       - Args: merchantId
       - Returns all events this merchant is assigned to
       - Includes event details and booth number

    Use v.id("merchantEvents") for IDs.
  </action>
  <verify>TypeScript compiles, Convex functions have proper types</verify>
  <done>Assignment mutations and queries implemented</done>
</task>
