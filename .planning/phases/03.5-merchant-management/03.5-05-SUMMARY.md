## Decisions Made

- Stock field is optional (null/undefined) to support unlimited items alongside tracked inventory
- Items reference merchantEvent junction table (not merchant directly) to support merchant-specific pricing per event
- Price stored as number in EVT tokens (not smallest unit) for admin-friendly display
- Join queries in getEventInventory return merchant details for complete context
- Color-coded stock warnings (yellow < 10, red = 0) for visual inventory management
