# Phase 4.3: User Dashboard UX - Context

**Gathered:** 2026-01-20
**Status:** Ready for planning

<domain>
## Phase Boundary

UI refresh of existing dashboard (`pwa/app/dashboard/page.tsx`) to match provided mockup design. Adapt existing working code rather than rebuilding from scratch. Focus on visual improvements and missing UI components.

**Existing functionality to preserve:**
- Auth flow via Privy
- Balance display (real-time via Convex)
- Top Up and Scan QR navigation
- Responsive mobile layout

**New UI components from mockup:**
- Header with user profile (initials from email, no notification button)
- Large balance card with gradient background and visibility toggle
- Action buttons: Top Up, Cash Out (Coming Soon toast)
- Recent Activities list (last 10 transactions)
- Bottom navigation with Home, Scan QR (elevated), History tabs

**Scope constraints:**
- Pixel-perfect mockup adherence where specified
- Defer backend features (category icons, full history filters) to later phases
- Cash Out is placeholder with toast notification
- History page is simple list (not full-featured)

</domain>

<decisions>
## Implementation Decisions

### Scope boundaries
- **Cash Out button**: Show button, display "Coming Soon" toast on tap (sonner), document for future phase
- **History page**: Simple list page with infinite scroll, no filters or search in this phase
- **Notification bell**: Remove entirely from header (not implemented yet)
- **Transaction data**: Use existing Convex transactions table with real data (not mock)

### Layout and visual design
- **Balance card gradient**: Use mockup gradient exactly: `linear-gradient(to bottom, rgba(19, 164, 236, 0.4), rgba(16, 28, 34, 0.95))`
- **Profile picture**: Initials only (first letter of each word from email), colored circle fallback, no Privy avatar lookup
- **Elevated Scan button**: Position `-12px` from bottom with shadow-ring effect matching mockup
- **Spacing**: Exact mockup spacing (padding, gaps, margins) — not design system grid

### Transaction list behavior
- **Dashboard limit**: 10 most recent transactions on dashboard
- **History page**: Infinite scroll (no pagination), shows all transactions
- **Empty state (dashboard)**: Friendly empty state with illustration and "Make your first payment" CTA
- **Empty state (history)**: "Start by topping up your wallet" with CTA button to /topup

### Transaction categorization
- **Icons**: Generic payment icon for all transactions now (Material Symbols `payments` or similar)
  - Category-specific icons deferred to backend phase (category field in item groups)
- **Category labels**: Show category badge below transaction amount
  - Source: Item group lookup via Convex (join transactions → items → item groups)
  - If no item group: Show "Payment" or omit category
- **Timestamp**: Relative time format ("2h ago", "Yesterday", "Oct 24")
- **Categories deferred**: Backend will add icon field to item groups later

### Bottom navigation
- **Structure**: 3-tab layout (Home left, Scan QR center elevated, History right)
- **Safe area handling**: Use React safe-area-view library for iOS notch/gesture area
- **Active indicator**: Filled Material Symbol + primary color (#13a4ec) for active tab
- **History destination**: Navigates to `/history` (simple list page, new route)

### Claude's Discretion
- Exact shadow values for elevated button (match mockup visual, not hardcoded values)
- Toast notification styling for "Coming Soon" message
- Empty state illustration choice (use existing or create simple CSS-based)
- Transaction list loading/skeleton states
- Balance toggle animation

</decisions>
