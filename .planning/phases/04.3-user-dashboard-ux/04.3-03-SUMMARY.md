## Decisions Made

1. **Amount color is white (not red)** - All customer transactions are expenses from the user's perspective, so they're not color-coded as "negative". Red is typically used for income vs. expense distinction, which doesn't apply here.

2. **Category label is optional** - Transactions from the payment flow may not have category data yet. The UI gracefully handles missing category data.

3. **Elevated scan button at 56px (size-14)** - Matches the action button size used in Top Up/Cash Out for consistency. Larger than standard tabs for visual prominence and accessibility.

4. **Safe-area-inset-bottom class** - Reuses existing utility from globals.css for notched device compatibility (iPhone X+, Android with gesture bars).

5. **"See All" link is placeholder** - Currently non-functional, will link to full History page in a future phase when complete transaction history is implemented.
