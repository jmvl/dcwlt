<task type="auto">
  <name>Task 3: Add atomic transferBalance mutation to wallets.ts</name>
  <files>pwa/convex/wallets.ts</files>
  <action>
Add a new `transferBalance` mutation to pwa/convex/wallets.ts that atomically:
1. Gets sender wallet by privyId (new pattern) or walletAddress (fallback)
2. Validates sender has sufficient balance (throw error if not)
3. Gets recipient wallet by walletAddress
4. Debits sender: `tokenBalance - amount`
5. Credits recipient: `tokenBalance + amount`
6. Updates fiatBalance for both (tokenBalance * 0.1 conversion rate)
7. Sets updatedAt to Date.now()

The mutation should accept:
- senderPrivyId: v.string() (primary identifier)
- recipientWalletAddress: v.string()
- amount: v.number() (in EVT tokens, not lamports)
- merchantId: v.optional(v.id("merchants"))
- itemId: v.optional(v.id("groupItems"))

Return { success: true, transactionId, newSenderBalance } on success.
Throw descriptive errors for: sender not found, recipient not found, insufficient balance.

Reference RESEARCH.md Pattern 1 for the exact implementation pattern with Convex atomic transactions.
DO NOT use separate mutations for debit/credit - must be atomic in one mutation.
