<task type="auto">
  <name>Task 3: Create lib/utils.ts with cn() utility</name>
  <files>pwa/lib/utils.ts</files>
  <action>
Create pwa/lib/utils.ts:
```typescript
import { clsx, type ClassValue } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

This function:
- Combines clsx (conditional classes) and tailwind-merge (conflict resolution)
- Enables conditional className logic: `cn("base-class", isActive && "active-class")`
- Used throughout Shadcn components for variant handling
  </action>
