<task type="auto">
  <name>Task 2: Create transaction queries and mutations</name>
  <files>pwa/convex/transactions.ts</files>
  <action>Create transaction queries and mutations at pwa/convex/transactions.ts:

1. Define query listMerchantTransactions(merchantId, filters):
   - Accept merchantId: Id<"merchants">
   - Accept optional filters: { dateRange?: "today" | "week" | "month" | "all", searchWallet?: string }
   - Query transactions.byMerchantByTime with merchantId
   - Filter by date range using timestamp comparisons:
     * today: timestamp > start of today
     * week: timestamp > 7 days ago
     * month: timestamp > 30 days ago
     * all: no time filter
   - Filter by customerWallet if searchWallet provided (includes match)
   - Sort by timestamp descending
   - Join with groupItems table using itemId to get item names
   - Return array with: { _id, timestamp, itemName, amount, customerWallet, status, signature }

2. Define query getMerchantSalesStats(merchantId, dateRange):
   - Accept merchantId: Id<"merchants">
   - Accept optional dateRange: "today" | "week" | "month" | "all"
   - Query transactions by merchantId and filter by dateRange
   - Calculate total sales: Sum of amounts for confirmed transactions
   - Calculate transaction count: Count of confirmed transactions
   - Calculate average: total sales / transaction count (handle division by zero)
   - Calculate today's sales: Filter for today's confirmed transactions
   - Return: { totalSales, transactionCount, averageTransaction, todaySales }

3. Define mutation createTransaction(merchantId, itemId, customerWallet, amount, signature):
   - Accept transaction details
   - Insert into transactions table with status="pending"
   - Return created transaction ID
   - Note: This will be called from payment flow in Phase 3

4. Export all functions (Convex codegen will handle API export)

5. Run `npx convex dev` to deploy functions

Follow existing query patterns in pwa/convex/itemGroups.ts for reference.</action>
  <verify>Queries execute without errors, types are generated correctly by Convex codegen, date filters work correctly, search filter works, stats calculations are accurate</verify>
