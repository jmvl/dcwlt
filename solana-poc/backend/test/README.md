# Test Suite for /api/topup Endpoint

This directory contains a comprehensive Test-Driven Development (TDD) test suite for the `/api/topup` endpoint in the Solana POC backend.

## Overview

The test suite validates the top-up functionality which transfers EVENT tokens from the pool wallet to user wallets using a key-sharding architecture.

### Test Coverage

The test suite includes:

1. **Successful Top-Up Operations** - Tests various amounts (10, 25, 50, 100)
2. **Missing Required Parameters** - Tests validation of walletId, shard1, amount
3. **Invalid Amount Values** - Tests negative, zero, excessive amounts
4. **Shard Validation** - Tests shard storage and retrieval
5. **Token Configuration** - Tests token system initialization
6. **Response Format** - Validates API response structure
7. **Edge Cases** - Tests special characters, unicode, concurrent requests
8. **Security Tests** - Tests SQL injection, XSS, prototype pollution
9. **Integration Tests** - Tests complete flow with /api/store-shard
10. **HTTP Methods** - Tests that only POST is allowed
11. **Data Type Validation** - Tests various input data types

## Prerequisites

Before running tests, ensure:

1. Node.js and npm are installed
2. Dependencies are installed: `npm install`
3. A test encryption key is set (automatically generated by tests)

## Mock vs Integration Tests

Currently, tests are designed as **validation tests** that validate:
- Request format
- Parameter validation
- Error handling
- Response structure

For **full integration tests** with actual Solana blockchain:

1. Run the setup-token.js script to initialize tokens
2. Update tests to use real wallet addresses
3. Mock the Solana connection for faster, deterministic tests

Example of mocking Solana connection:

```javascript
// In setup.js
const { Connection } = require('@solana/web3.js');
jest.mock('@solana/web3.js', () => {
  const actual = jest.requireActual('@solana/web3.js');
  return {
    ...actual,
    Connection: jest.fn().mockImplementation(() => ({
      sendTransaction: jest.fn().mockResolvedValue('mock-signature'),
      confirmTransaction: jest.fn().mockResolvedValue({ value: { err: null } }),
    })),
  };
});
```

## Troubleshooting

### Tests Fail with "ENCRYPTION_KEY not set"

The encryption key is automatically generated. If you see this error, ensure `test/setup.js` is being loaded.

### Tests Timeout

Increase timeout in `jest.config.js`:

```javascript
testTimeout: 60000, // 60 seconds
```

### Port Already in Use

Ensure the backend server is not running before tests:

```bash
# Stop any running backend
pkill -f "node server.js"
```

### Cannot Find Module

Ensure dependencies are installed:

```bash
npm install
```
